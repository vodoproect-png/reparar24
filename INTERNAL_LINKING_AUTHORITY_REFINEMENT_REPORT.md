## EMERGENCY SERVICE SIGNALS

### Current Emergency Service Implementation

**Code Analysis (`lib/linking/internal.ts`):**

```typescript
export function getEmergencyServiceLinks(
  services: Service[],
  locale: Locale
): InternalLink[] {
  return services
    .filter((s) => s.available24h)
    .map((service) => ({
      href: getServiceUrl(service.slug, locale),
      title: `${service.name} Urgente 24h`,
      description: service.description,
    }))
}
```
