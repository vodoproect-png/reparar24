## Technical Implementation

### Next.js 15 Metadata API

**Architecture:** File-based icon generation using ImageResponse API

### Files Created

**1. `app/icon.tsx`**
- **Purpose:** Generate favicon.ico and various sizes
- **Output Size:** 32x32px
- **Format:** PNG
- **Automatic Sizes Generated by Next.js:**
  - `favicon.ico` (16x16, 32x32 multi-size)
  - `/icon` route (dynamic sizing)

**Code Structure:**
```typescript
import { ImageResponse } from 'next/og'

export const size = { width: 32, height: 32 }
export const contentType = 'image/png'

export default function Icon() {
  return new ImageResponse(
    <div style={{ /* blue circular background */ }}>
      <svg>
        {/* House + Wrench SVG */}
      </svg>
    </div>
  )
}
```

**2. `app/apple-icon.tsx`**
- **Purpose:** Apple Touch Icon for iOS/iPadOS
- **Output Size:** 180x180px (Apple standard)
- **Format:** PNG
- **Features:**
  - 22.5% border-radius (Apple rounding standard)
  - Higher resolution for retina displays
  - Same design at larger scale
  - More detail visible (window cross-patterns, wrench grip lines)

**Code Structure:**
```typescript
import { ImageResponse } from 'next/og'

export const size = { width: 180, height: 180 }
export const contentType = 'image/png'

export default function AppleIcon() {
  return new ImageResponse(
    <div style={{ /* blue circular background, 22.5% radius */ }}>
      <svg width="140" height="140">
        {/* Detailed House + Wrench SVG */}
      </svg>
    </div>
  )
}
```

### Auto-Generated Routes

**Next.js automatically creates:**
```
/icon → 32x32 favicon
/apple-icon → 180x180 Apple Touch Icon
favicon.ico → Multi-size ICO file
```

**No manual file management required!** ✅

```

1. Next.js reads app/icon.tsx
2. Executes default export function
3. ImageResponse generates PNG
4. Saves to .next/static/media/
5. Creates /icon route

Runtime:
1. Browser requests /icon
2. Next.js serves pre-generated PNG
3. With cache headers (immutable)
4. Subsequent requests cached by:
   - Browser cache

   - Service Worker (if PWA)
```
