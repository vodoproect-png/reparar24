# ProcessStepsV3 3D Icons

This folder contains the 3D icon assets for the ProcessStepsV3 component.

## Required PNG Files:

1. **process-3d-01-contacto.png**
   - 3D blue phone + chat bubble icon
   - Used for Step 01: "Contacto"

2. **process-3d-02-valoracion.png**
   - 3D green calendar + clock icon
   - Used for Step 02: "Diagnóstico"

3. **process-3d-03-reparacion.png**
   - 3D Reparar24 plumber character holding orange wrench
   - Used for Step 03: "Presupuesto"

4. **process-3d-04-garantia.png**
   - 3D purple shield + checkmark icon
   - Used for Step 04: "Reparación"

## Specifications:

- Format: PNG with transparency
- Recommended size: 256x256px or 512x512px
- Optimized for web
- Source: v0-design-system-blueprint repository

## Usage:

These icons are referenced in: `components/ds/ProcessStepsV3.tsx`

Paths:
- `/icons/process-3d-01-contacto.png`
- `/icons/process-3d-02-valoracion.png`
- `/icons/process-3d-03-reparacion.png`
- `/icons/process-3d-04-garantia.png`
