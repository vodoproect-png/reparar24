## 3. INTEGRATION METHOD

### 3.1 Architecture Pattern: Adapter

**Strategy**: Isolate hero presentation from data layer using adapter pattern

```
Data Layer          Adapter Layer           Presentation Layer
───────────        ─────────────────        ──────────────────
data/services.ts → hero-adapter.ts    →    ServiceHeroV2.tsx
lib/config/       → (maps data)       →    (renders UI)
contact.ts
```

**Benefits**:
- ✅ Data sources unchanged
- ✅ Easy to modify mapping
- ✅ Component remains reusable
- ✅ Simple rollback
