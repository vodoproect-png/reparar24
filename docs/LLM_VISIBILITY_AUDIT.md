# LLM Visibility Audit

Цель аудита: проверить, насколько Reparar24 понятен поисковым ботам, AI Overviews, ChatGPT/Bing/Perplexity-подобным ответным системам и другим LLM-агрегаторам.

## Что уже хорошо

- На коммерческих страницах есть индексируемый HTML, а не только клиентский рендер.
- Основные шаблоны используют `Service`, `FAQPage`, `BreadcrumbList` и `LocalBusiness`.
- У страниц есть коммерческие SEO-тексты, FAQ, блоки доверия, цены, районы и CTA.
- Контент разделен по намерениям: главная, категории, дочерние услуги, города, районы.
- У сайта есть единая структура услуг, которую можно превратить в entity graph.

## Что исправлено

- Добавлен единый `Organization` и `WebSite` JSON-LD на уровне испанского layout.
- Убран неподтвержденный `sameAs` на соцсети, чтобы не создавать ложные entity-сигналы.
- Убран `SearchAction` на `/buscar`, пока на сайте нет реальной страницы поиска.
- `logo.png` в structured data заменен на существующий брендовый `reparar24-og.jpg`.
- `Service` schema получила стабильные `@id`, `url`, `mainEntityOfPage`, `provider`, `availableChannel`, `offers`.
- `LocalBusiness` и `Organization` получили `hasOfferCatalog` со всеми ключевыми услугами.
- Добавлен автоматический аудит:

```bash
npm run build
npm run audit:llm
```

Отчет сохраняется в:

```text
.tmp/llm/llm-visibility-audit.json
```

## Что проверяет аудит

- Наличие и парсинг JSON-LD.
- Наличие `Organization` и `WebSite` на индексируемых страницах.
- Наличие `Service` на услуговых URL.
- Наличие `LocalBusiness` на главной.
- Наличие `BreadcrumbList` и `FAQPage`.
- Количество `h1` и `h2`.
- Минимальный объем отрендеренного текста.
- Рискованные сигналы: несуществующий `logo.png`, неподтвержденный `sameAs`, `SearchAction` на отсутствующий поиск.
- Возможный mojibake в отрендеренном тексте.

## Оценка текущей готовности

После исправления schema-слоя сайт уже хорошо подготовлен под LLM extraction на уровне структуры: страницы имеют понятный тип, услугу, бренд, телефон, оффер, город/район и FAQ.

Главный остаточный риск для LLM-выдачи не технический, а авторитетность:

- Нужно больше внешних упоминаний бренда Reparar24.
- Нужно больше подтвержденных сущностей: Google Business Profile, каталоги Испании, локальные citations.
- Нужны независимые отзывы и упоминания NAP: бренд, телефон, адрес, сайт.
- Желательно добавить реальные `sameAs` только после подтверждения профилей.

## Следующий логичный шаг

1. Довести аудит до зеленого состояния по всем предупреждениям.
2. Подключить реальные external entity-сигналы: GBP, Páginas Amarillas, Cylex, Hotfrog, Yelp España, 11870.
3. После подтверждения профилей добавить проверенные `sameAs` в `generateOrganizationSchema`.
4. Запустить offpage/citation conveyor и фиксировать каждое размещение в базе ссылок.
