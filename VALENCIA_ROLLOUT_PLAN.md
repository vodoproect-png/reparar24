## Contingency Plans

### Scenario 1: Slow Indexation (<50% by Week 2)

**Actions:**
1. Request remaining URLs manually via GSC
2. Increase internal linking to Valencia pages
3. Check robots.txt not blocking
4. Verify sitemap is being crawled
5. Add more external signals (citations, GMB)

### Scenario 2: High Indexation but Low Impressions

**Actions:**
1. Review target keywords
2. Optimize meta titles/descriptions
3. Improve schema markup
4. Check query competition level
5. Adjust content for search intent

### Scenario 3: Good Impressions but Low CTR

**Actions:**
1. A/B test meta descriptions
2. Add review stars schema
3. Improve title tag appeal
4. Check SERP snippet display
5. Add FAQ schema

### Scenario 4: Manual Action Received

**Actions:**
1. STOP rollout immediately
2. Review flagged pages
3. Analyze content issues
4. Fix semantic differentiation
5. Request reconsideration
6. DO NOT proceed to Phase 2
